Task Timer
项目说明
一个轻量级的Python任务耗时统计工具，用于便捷记录多个任务的执行时间，分析耗时分布与生成汇总报告。

代码用途
1. 用于学习、工作中多任务并行时的时间管理，直观掌握各任务耗时分布
2.可嵌入其他项目中，作为性能监控、任务调度的辅助模块

核心功能
1. 任务开始/结束记录：通过`start()`和`end()`方法配对使用，精准记录任务时间节点
2. 实时耗时计算：任务结束时自动计算并打印耗时，显示精确到0.01秒
3. 多任务支持：支持多个任务同时运行并独立计时
4. 汇总报表生成：通过`summary()`方法生成格式化的耗时汇总
5. 人性化时间展示：同时支持时间戳（用于计算）和可读时间格式（用于展示）
6. 支持导出CSV

快速开始
from task_timer import TaskTimer
import time

timer = TaskTimer()

#普通计时
timer.start("数据处理")
time.sleep(1)
timer.end("数据处理")

# 自动计时（推荐）
with timer.task("模型训练"):
    time.sleep(2)

timer.summary()
